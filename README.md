# SONG WIJONG Portfolio

송위종의 영상 포트폴리오 웹사이트입니다. 별도의 로그인 없이 PC와 모바일 브라우저에서 바로 볼 수 있도록 만든 정적 HTML 사이트입니다.

## 파일 수정 위치

- `index.html`: 메인 화면의 문구와 메뉴
- `awards.html`: AWARDS 목록과 제목
- `works.html`: AI-커머스 목록
- `participated.html`: 참여작 목록
- `styles.css`: 공통 글꼴, 색상, 상단 메뉴, 모바일 화면
- `awards.css`: AWARDS 화면 크기와 배치
- `commerce.css`: AI-커머스 썸네일 크기와 배치
- `videos/`: 공모전 영상
- `commerce/`: AI-커머스 영상과 썸네일

## GitHub Pages 공개

GitHub 저장소의 **Settings → Pages**에서 배포 원본을 **Deploy from a branch**, 브랜치를 **main**, 폴더를 **/(root)**로 선택하면 됩니다.

사이트 주소는 보통 `https://GitHub아이디.github.io/저장소이름/` 형식입니다.

## 모바일 구성

화면 너비에 따라 메뉴, 영상 목록, 제목 크기가 자동으로 바뀝니다. 모바일에서는 상단의 `MENU` 버튼으로 메뉴를 열 수 있습니다.
